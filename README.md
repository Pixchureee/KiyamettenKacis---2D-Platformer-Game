# 🎮 [Kıyametten Kaçış - 2D Platformer]

> 🕒 Developed in **August 2022**.  
> ⌛ Developed in **3 days**.

---

## 🧠 Concept

This game was developed for **Watermelon Jam**.  
Theme: **"Nothing Is Permanent(Hiçbir şey kalıcı değildir)"**

Theme adaptation: The theme is emphasized through the storyline presented at the end of each level and the backstories of the special abilities collected throughout the game.

---

## 🕹️ How to Play?

1. Controls:  
   - A / Left Arrow (move left) - D / Right Arrow (move right) - Space (jump)
2. Objective:  
   - The player must complete the levels without being caught by the approaching apocalypse.  
   - Touching the flames → game over  
3. Language  
   - Turkish

🎯 **Goal:** Reach the end of the game by completing all levels.
